---
title: "veryfront/security"
description: "Security layer for input validation with size limits, application authentication, CORS configuration, CSP and security headers, path traversal prevention, and secure filesystem access."
order: 35
---

## Import

```ts
import {
  applyCORSHeaders,
  applyCORSHeadersSync,
  applyCsrfCookie,
  applySecurityHeaders,
  buildCacheControl,
  cors,
} from "veryfront/security";
```

## Examples

### Apply response security headers

```ts
import { applySecurityHeaders, generateNonce } from "veryfront/security";

const response = new Response("Ready");
applySecurityHeaders(response.headers, false, generateNonce(), null);
```
