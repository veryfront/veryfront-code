Veryfront Code is an Apache-2.0 open-source framework. It works standalone and
does not require a Veryfront account or Veryfront Cloud.

Every agent needs model inference. Where inference runs is independent of where
you develop or deploy the app.

## Choose a path

| Goal                                                                  | Start here                                |
| --------------------------------------------------------------------- | ----------------------------------------- |
| Build and evaluate locally with your provider key                     | [Local quickstart](./quickstart.md)       |
| Use the AI Gateway and deploy with Veryfront Cloud                    | [Cloud quickstart](./cloud-quickstart.md) |
| Deploy in your own cloud, private network, or on-premises environment | [Self-host](../guides/self-hosting.md)    |

## Continue after the quickstart

Use [Task guides](../guides/index.md) to add capabilities, test changes and deploy. The [API reference](../api-reference/index.md) lists imports, options and types.
