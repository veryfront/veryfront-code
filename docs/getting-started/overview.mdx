## What is Veryfront Code

Veryfront Code is the TypeScript and React framework for building AI applications in your editor and repository. Define agents, tools, workflows, evaluations, routes, and chat interfaces in one project.

Run locally with your provider key, deploy with Cloud, or self-host. See the [platform lifecycle](/concepts) for how Code connects to Studio, Cloud, and Agent.
