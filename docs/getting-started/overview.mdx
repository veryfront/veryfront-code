Veryfront Code is a TypeScript and React framework for apps and agents. Define their behavior in code, run locally and verify changes with evaluations.

Code is open source and runs without a Veryfront account. Use your own model provider, connect Cloud or self-host.

## Start building

[Build and evaluate your first agent locally](./quickstart.md). The tutorial creates a chat app, tests a tool call and runs an evaluation.

If you already have an app, [add Veryfront to the project](./add-to-existing-project.md).
